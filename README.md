# BK Control — Portfólio do Projeto de Estágio

Portfólio do projeto de estágio **Informatizando Processos BK / BK Control**: um sistema web de gestão operacional para a Bread King Londrina.

**Site:** https://caioribas2003.github.io/Portifolio-BK-Control/

## Conteúdo

1. Página inicial: nome, objetivo e descrição do projeto
2. Sobre o projeto: problema, tecnologias e arquitetura
3. Casos de uso e cronograma
4. Documentação: diagramas UML e artefatos de requisitos
5. Telas e vídeo de demonstração
6. Relatório de Estágio (PDF)
7. Identificação do aluno

## Tecnologia do site

Site estático em HTML, CSS e JavaScript puro, sem etapa de build. Os logos da stack vêm do [Devicon](https://devicon.dev/), e o vídeo está incorporado do YouTube.

Para ver localmente:

```bash
python -m http.server 8090
```

Depois, abra http://localhost:8090.
